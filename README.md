# Rio de Janeiro (municipal chambers): law history in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law: this is the municipal law of Rio De Janeiro, Brazil, which global-law reads at `brazil/rio-de-janeiro/municipal/acts/`.

The municipal laws of Rio de Janeiro's cities as a git history, one folder per city, one commit per law on the day it took effect.
